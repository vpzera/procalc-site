# Site da Procalc Perícia Contábil

Site estático (HTML + CSS), publicado no Cloudflare Pages a cada push na branch `main`.

- `index.html`: página inicial
- `artigos.html` e `artigo-*.html`: blog
- `blog.css`: estilos das páginas de artigos
- `marca.png`: símbolo da marca

Não há etapa de build: no Cloudflare Pages, deixe o comando de build vazio e o diretório de saída como `/`.
